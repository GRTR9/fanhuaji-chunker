# 繁化姬長檔轉換器

把超長的文字檔自動切成小段，逐段送到[繁化姬](https://zhconvert.org) API 轉換，再合併回一個檔案。

## 安裝與執行

需要 Python 3.9 以上（Windows 官方安裝版已內建 tkinter）。

**Windows：直接雙擊 `start.bat`。** 第一次會自動在 `.venv` 建立虛擬環境並安裝套件，之後只有 `requirements.txt` 變動時才重裝。

> **ARM64 Windows（例如 Snapdragon 筆電）**：tkinterdnd2 附的 ARM64 拖放元件與 Python 內建的 Tcl 8.6 不相容，
> 程式會自動改用 Windows 原生拖放，一樣可以把檔案或資料夾從檔案總管拖進視窗，不需另外安裝任何東西。

手動執行：

```bash
pip install -r requirements.txt
python app.py
```

## 功能

- **自動切段**：以「行」為單位打包，每段預設 20,000 字元；單行過長時會在 。！？ 等句尾標點處切開。合併後的換行、空白跟原檔完全一致。
- **失敗重試**：遇到逾時、HTTP 429/5xx 會自動等待再重試（2、4、8… 秒）。
- **太長自動切小**：若某段疑似太長（HTTP 413/502/504、逾時、回應不是 JSON），重試一次後會自動對半切開重送，並記住可行長度，後面的段落直接先切小（最小 500 字）。JSON 裡超過每段上限的單一字串也會先切開再轉。
- **中斷續傳**：轉好的段落會先存在輸出檔旁的 `.zhcache`。按「停止」或程式當掉後，用相同設定再跑一次，會從中斷的地方接著做；整檔完成後會自動刪除快取。
- **JSON 模式**：`.json` 檔只轉換含中文的字串值，鍵名、數字、結構都不動（可在進階設定勾選連鍵名一起轉）。輸出時會沿用原檔的縮排。
- **其他文字檔**：`.txt / .md / .srt / .ass / .jsonl / .csv / .yml …` 都用純文字模式處理。
- **編碼**：讀取時自動判斷 UTF-8 / UTF-8 BOM / UTF-16 / GB18030 / Big5，輸出預設 UTF-8。
- 繁化姬的模組開關、轉換前／後取代、保護詞都可以在「進階設定」填。
- 設定會存在 `~/.zhconvert-long.json`。

## 只用核心、不開 GUI

```python
from zhconv_core import ConvertOptions, convert_file
convert_file("小說.txt", "小說_tw.txt", ConvertOptions(converter="Taiwan"))
```

## 調整建議

- 程式會自動把太長的段落切小；若紀錄裡常出現「疑似太長，自動切成…」，可直接調低「每段字元數」（例如 10000 或 5000），省去每個檔案一開始的試錯請求。
- 請求間隔預設 0.5 秒，對繁化姬伺服器比較友善，請不要設成 0 狂打。

## 注意

- 繁化姬一般使用免費，**商業使用需付費**，詳見 <https://docs.zhconvert.org/commercial>。
- 繁化姬的伺服器可能留存你送出的文字以改進轉換品質，機密文件請自行斟酌。
- 切段處的前後文會被切開，極少數跨段詞彙可能轉換得跟一次轉整篇略有不同；切在換行處能把這個影響降到最低。
- 本專案為非官方工具，與繁化姬及其作者無關。
- API Key 會以明文存在 `~/.zhconvert-long.json`，請勿分享該檔案。
